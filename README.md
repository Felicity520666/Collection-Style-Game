# Collection Style Game

## About This Game

Hello there! Welcome to this KPop Demon Hunters-themed collection game, where
you play as Rumi and try to catch Jinu! (๑>؂•̀๑) This is a simple game, and I
hope you have fun and relax.

## How to Play

Use the left and right (or A and D) arrow keys on your keyboard to move Rumi. Catch Jinu
five times to win. If you miss him, you lose... But don't give up! Click the game to play again.

## Features

- Responsive game layout
- KPop Demon Hunters themed
- Score tracking with win and loss screens
- Click-to-restart gameplay
